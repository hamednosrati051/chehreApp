# اپ اندروید جدید (فقط تصویر) — نسخه‌ی اول

اپ نیتیو اندروید (Kotlin + Jetpack Compose)، جدا از اپ نورا.
بک‌اند آن در `../backend` است و با همین API صحبت می‌کند.
بخش صدا پارک شده و در این نسخه هیچ صفحه/آیتم صدایی ندارد.

## نکات مهم قبل از انتشار

- **پکیج موقت:** `ir.inourai.newapp` فقط جای‌نگهدارنده است.
  حامد برند را ته کار می‌گوید؛ پکیج باید **قبل از اولین آپلود در بازار**
  نهایی شود (بعد از انتشار در بازار قابل تغییر نیست).
- **آدرس بک‌اند:** در `data/Api.kt` مقدار `BASE_URL` فعلاً جای‌نگهدارنده
  است و موقع استقرار با آدرس واقعی بک‌اند خود اپ عوض می‌شود.
- **SKUها و کلید RSA بازار:** از پنل بازار خود اپ می‌آیند (نه نورا)؛
  تا ساخته نشوند، خرید واقعی کار نمی‌کند ولی ساختار کامل است.

## صفحه‌ها (نوار زیر در همه‌ی صفحه‌ها)

خانه، جستجو، تصاویر من، پروفایل.

- خانه: کارت دنیاهای عکس + پیشنهادی‌ها + گالری خود اپ (عکس‌های تاییدشده)
- دنیاها: قرص‌های دسته‌بندی (پیشنهادی = برچسب، نه دسته) + گرید دنیا
- ساخت عکس: انتخاب سلفی → آپلود → لودینگ ساخت → نتیجه + ارسال به گالری
- تصاویر من: عکس‌های ساخته‌شده‌ی خود کاربر + ارسال هر عکس به صف تایید گالری
- پروفایل: سکه، عکس رایگان باقی‌مانده، پک‌ها (خرید بازار)، بازیابی
  خریدهای ناتمام، خروج
- لاگین موبایل + OTP

## پرداخت بازار (IAB)

`billing/BazaarBilling.kt` با AIDL سرویس بازار وصل می‌شود
(تگ `<queries>` برای `com.farsitel.bazaar` در Manifest هست):
خرید SKU ← وریفای سروری (RSA + idempotency) ← consume ← رفرش موجودی.
خریدهای ناتمام موقع شروع اپ بازیابی می‌شوند. پک‌ها consumable هستند،
پس همان پک بلافاصله دوباره قابل خرید است.

## چیزهای ناتمام (عمداً)

- آدرس واقعی بک‌اند خود اپ (تصمیم هاست با حامد).
- SKUها و کلید RSA بازار خود اپ (پنل حامد).
- برند و پکیج نهایی (ته کار با حامد).
- اسپلش اول اپ: جای Lottie آماده است؛ انیمیشن فانتزی و عامیانه
  با نهایی‌شدن برند ساخته می‌شود.
